# Emmanuel Oberabor Portfolio

Static portfolio for data analysis, automation, and full-stack development.

## Pages

Home, Skills, Projects, Reviews, Resumes, and Contact. Project case studies are rendered by `project.html?id=...`.

The resume page offers browser previews and PDF downloads for the Data Analyst and Full Stack Developer resumes.

## Development

Run `python -m http.server 8080` from this directory and visit http://localhost:8080.

## Deployment

GitHub Pages publishes the root of the `main` branch. No build command or dependencies are required. Keep relative asset paths intact. Private resume collections, source documents, and development tools are stored outside this directory.

Operations screenshots contain fictional demonstration details, confirmed by the portfolio owner.
