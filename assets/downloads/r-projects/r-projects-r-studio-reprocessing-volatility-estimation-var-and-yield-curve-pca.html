MULTI-ASSET RISK PROFILE AND TREASURY CURVE ANALYSIS

Pre-processing summary

The script starts in a clean R session, sets the random-number generator as requested, and loads data.table. It pulls the full stock-price file, converts the text date column to a proper Date, and keeps only the 65 tickers listed in the exercise. Rows are filtered to the window 2023-02-10 – 2025-04-16 and sorted oldest to newest.

Daily log-returns are produced with diff(log(price)). A quick checkpoint prints the first and last rows of the log-return table; the values match those quoted (0.030799… / –0.037293…, etc.), so prices are aligned and the date filter is correct.

The Treasury yield file is read next. Dates are parsed, the rows are sorted, and the “1.5 Month” column (which contains gaps) is removed.

The cleaned stock prices, their log-returns, and the trimmed yield table are packed into one RDS file called prepped_data.rds. This file is the starting point for Part I, where the annualised volatilities will be calculated.

This is the code used to accomplish the pre-processing:

Part I : Volatility estimation report

Procedure

Converted prices to daily log-returns \(r_t = \ln\!\bigl(P_t/P_{t-1}\bigr)\)

Computed the sample standard deviation of each return series.

Annualised each result with 252\sqrt{252}252​ (trading-day convention).

Annualised each standard deviation by multiplying it by √252 ​ (trading-day convention).

Rounded values to four decimals.

This is the code used to accomplish the volatility estimation report:

rm(list=ls())
RNGkind(sample.kind="Rejection")
library(data.table)
prepped <- readRDS("prepped_data.rds")
logret <- prepped$log_returns
tickers <- names(logret)
vol <- sapply(logret, sd, na.rm=TRUE) * sqrt(252)
vol <- round(vol, 4)
idx_min <- which.min(vol)
idx_max <- which.max(vol)
cat("Volatility estimates (first ten):\n")
print(head(vol, 10))
cat("\nSmallest σ =", vol[idx_min], "for", tickers[idx_min], "\n")
cat("Largest σ =", vol[idx_max], "for", tickers[idx_max], "\n")

Part II : Historical-simulation VaR summary

Method

Daily log-returns from Part I were re-used.

A fixed stake of 20 000 USD in each of the 65 tickers gives one scalar series of daily profit / loss:

P ⁣Lt=∑j=16520 000×rj,t.P\!L_t=\sum_{j=1}^{65}20\,000\times r_{j,t}.PLt​=j=1∑65​20000×rj,t​.

The 10-th percentile of that series (hist-sim approach) is the 1-day 90 % VaR, rounded to the nearest dollar and kept negative.

The smallest and largest single-day P / L values in the same series were recorded.

Here is the code used to achieve the yield curve:

rm(list=ls())
RNGkind(sample.kind="Rejection")
library(data.table)
p <- readRDS("prepped_data.rds")
y <- p$yields[Date >= as.Date("2025-01-01") & Date <= as.Date("2025-04-16")]
m <- c(
"1 Mo" = 1/12, "2 Mo" = 2/12, "3 Mo" = 3/12, "4 Mo" = 4/12,
"6 Mo" = 6/12, "1 Yr" = 1, "2 Yr" = 2, "3 Yr" = 3,
"5 Yr" = 5, "7 Yr" = 7, "10 Yr" = 10, "20 Yr" = 20,
"30 Yr" = 30
)
setcolorder(y, c("Date", names(m)))
r <- as.matrix(y[, -1]) / 100
T <- unname(m)
n <- length(T)
fwd <- matrix(NA_real_, nrow = nrow(r), ncol = n - 1)
for (i in 2:n) {
fwd[, i - 1] <- (r[, i] * T[i] - r[, i - 1] * T[i - 1]) / (T[i] - T[i - 1])
}
colnames(fwd) <- paste0("Fwd_", names(m)[-1])
e <- eigen(cov(fwd))
load12 <- round(e$vectors[, 12][1:3], 4)
prop <- e$values / sum(e$values)
need <- which(cumsum(prop) >= 0.85)[1]
cat("PC12 loadings (first three):", load12, "\n")
cat("PCs needed for ≥85% variance:", need, "\n")
